# 🧠 NEUROPLAY
### Online Gamified Test for Dyslexia Risk Screening

## About the Project
NEUROPLAY is an educational web-based project designed to explore dyslexia risk screening through interactive games and machine learning.

## Features
- User Registration and Login
- Interactive Gamified Questions
- Machine Learning-Based Risk Screening
- Results Page
- User Dashboard
 
## Machine Learning
- Random Forest Classifier
- Scikit-learn
- Model Training and Evaluation
- Prediction using the trained ML model

## Technologies Used
- Python
- HTML
- CSS
- JavaScript
- FastAPI
- SQLite
 
## Project Structure
- backend – Backend implementation
- frontend – User interface
- ml.ipynb – Machine learning notebook
- neuroplay_models.joblib – Trained model
- NeuroPlay.pptx – Project presentation
